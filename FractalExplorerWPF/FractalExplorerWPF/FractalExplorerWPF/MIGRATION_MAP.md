# FractalExplorer WPF Migration Map

Последнее обновление: 2026-06-09.

## Перенесено и работает

- WPF-проект `net10.0-windows` и главное окно менеджера.
- Каталог всех фракталов с группировкой по семействам.
- Выбор элемента, название, описание и статическое изображение предпросмотра.
- Список вариантов порядка тайлов как элемент будущей настройки.
- Все PNG-ресурсы из WinForms `Resources`.
- Все ICO-ресурсы из `Pictures/ico`; `FractalExplorer.ico` назначен иконкой приложения.
- Математические типы `ComplexDecimal`, `ComplexDouble`, `DecimalMath`.
- Базовые состояния сохранений семейства Mandelbrot/Julia.
- JSON-конвертер `ComplexDecimal`.

## Скопировано как исходный материал

Каталог `MigrationSource` исключён из компиляции. В нём сохранены без адаптации:

- все классы из `Engines`;
- реализации форм семейства Mandelbrot;
- весь старый `SaveIO`;
- все старые `Utilities`, включая тайловый диспетчер, темы, палитры и сервисы;
- старые пользовательские `Controls`;
- исходный `LauncherHubForm` с Designer и RESX.

Эти файлы являются контрольной копией для миграции, а не рабочей частью WPF.

## Не перенесено или не реализовано

- Запуск окон фракталов по кнопке или двойному клику.
- WPF-страницы фракталов и навигация между ними.
- Реальный рендер предпросмотра; Hub показывает готовые PNG.
- Настройки и сохранение выбранного порядка тайлов.
- Менеджер тем и редактор тем; Hub временно использует фиксированную тёмную тему.
- Менеджер сохранений и диалог сохранения/загрузки.
- Рендер через `WriteableBitmap`.
- Палитры и конвертер цвета.
- Высококачественный экспорт изображений.

## Следующий рекомендуемый этап

1. Выделить из `FractalMandelbrotFamilyEngine` независимый рендер в BGRA-буфер.
2. Подключить буфер к WPF `WriteableBitmap`.
3. Создать первую страницу классического Mandelbrot без сохранений.
4. После стабилизации страницы адаптировать контракты и UI менеджера сохранений.
